Desenvolvido para simular o fluxo real de um e-commerce, este projeto é uma aplicação de carrinho de compras que calcula e atualiza o valor total do pedido em tempo real à medida que o usuário escolhe os produtos e suas quantidades. A interface moderna e intuitiva foi estruturada com HTML5 e estilizada com CSS Grid e Flexbox, garantindo um design atraente e organizado. Toda a inteligência e o dinamismo da página são controlados por JavaScript, que manipula os elementos da tela instantaneamente a cada adição ou remoção de itens sem a necessidade de recarregar a página, unindo uma ótima experiência de usuário a um código eficiente.

Desenvolvido para simplificar a organização de eventos, este projeto é uma aplicação de Amigo Secreto que automatiza o sorteio de nomes de forma rápida e justa. A interface moderna e de alto contraste foi estruturada com HTML5 e estilizada com técnicas avançadas de CSS, garantindo um layout limpo, elegante e de fácil navegação. Toda a inteligência da aplicação é controlada por JavaScript, que gerencia a lista de participantes em tempo real, utiliza um algoritmo de embaralhamento dinâmico para garantir sorteios completamente aleatórios e exibe os pares formados instantaneamente na tela, proporcionando uma excelente experiência prática e fluida para o usuário.
